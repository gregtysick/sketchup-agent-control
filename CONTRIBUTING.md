# Contributing to SketchUp Agent Control

Thank you for considering a contribution. Please keep changes small, reviewable, and grounded in official SketchUp, MCP, and language documentation.

- Do not add arbitrary code execution, network listeners, or model-changing commands to the read-only milestone.
- Add or update tests for validation and safety behavior.
- Do not commit models, screenshots, bridge data, exports, backups, logs, credentials, or machine-specific paths.
- State clearly whether a check was automated or manually exercised inside SketchUp.
- Open an issue or discussion before proposing a new write command or architectural boundary.
